# 研究二数字心理支持方案材料

本仓库用于收录一项心理学硕士论文研究二的数字心理支持材料，供研究方法说明与学术交流使用。研究采用七日微信小程序形式：X组为整合干预实验组，Y组为支持性对照组，Z组为非随机测量参照组。

## 材料目录

| --- | --- |
| [X组七日心理练习](materials/X_整合干预实验组完整材料.pdf) | Day1、Day7研究流程及Day2至Day6英雄之旅、CARE、BPS、人格可改变信念、ABC与行动计划 |
| [Y组七日支持性练习](materials/Y_支持性对照组完整材料.pdf) | Day1、Day7研究流程及Day2至Day6日常内容描述、记忆与注意、典型的一天、分享感受、感官探索 |
| [X/Y组共同研究材料](materials/XY_共同研究材料.pdf) | 共同说明、每日练习前后状态测量、每日状态记录与安全支持 |
| [游戏化陪伴与卡牌](materials/游戏化陪伴与卡牌材料.pdf) | 21张陪伴卡文字、萌宠成长、七日进度及旅程纪念卡 |

## 公开范围

本套文件保留七日心理练习的文字、指导语、案例、互动题目、选项、开放式任务及必要的条件呈现说明。文件名沿用完整练习材料目录，但公开副本不等同于本地全要素归档：尚未确认再分发权限的问卷题文、图片、视频截图及独立音视频文件未发布；对应名称及位置在材料中保留。媒体索引中的“未公开”不表示该媒体没有在研究中使用。

本仓库不包含参与者姓名、账号、联系方式、个人作答或其他研究数据，也不包含小程序源码、云数据库、内部配置、后台管理文件、登录方式、展示账号及开发测试材料。

## 情境案例与解释边界

CARE、Project Personality及YES相关中文同伴案例属于文化适配的情境案例，不代表真实中国参与者的经历。原练习文字中的故事或同伴叙述应在这一情境材料框架下理解。

本材料用于研究方法说明和学术交流，不构成已经验证有效的NSSI治疗方案，也不能代替专业评估与治疗。

## Reading in English

These materials describe a seven-day WeChat-based digital psychological support study. Group X received an integrated intervention, group Y received supportive control activities, and group Z served as a non-randomized measurement reference group. No participant data are included. Chinese peer scenarios are culturally adapted examples, not accounts of actual Chinese study participants. The materials are shared for methodological transparency and academic exchange, not as an established NSSI treatment.
